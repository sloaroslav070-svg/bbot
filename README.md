# Telegram Bot 🤖

Простой Telegram бот на Node.js с поддержкой основных команд.

## Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/sloaroslav070-svg/bbot.git
cd bbot
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения

Создай файл `.env` в корне проекта:
```
TELEGRAM_BOT_TOKEN=your_token_here
NODE_ENV=development
```

**Где взять токен?**
1. Открой Telegram и напиши @BotFather
2. Создай нового бота командой `/newbot`
3. Скопируй токен в `.env`

### 4. Запуск бота

**Обычный запуск:**
```bash
npm start
```

**Режим разработки (с перезагрузкой при изменении файлов):**
```bash
npm run dev
```

## Доступные команды

- `/start` - Приветствие и основная информация
- `/help` - Справка по всем командам
- `/ping` - Проверка статуса бота
- `/time` - Текущее время сервера
- **Обычное сообщение** - Бот просто ответит

## Как добавить новую команду?

Пример новой команды `/hello`:

```javascript
bot.onText(/\/hello/, (msg) => {
  const chatId = msg.chat.id;
  bot.sendMessage(chatId, 'Привет! 👋');
});
```

## Безопасность

⚠️ **ВАЖНО:**
- Никогда не коммити файл `.env` с реальным токеном
- Используй только `.env.example` в репо как пример
- Если случайно опубликовал токен, срочно создай новый через @BotFather

## Технологии

- **Node.js** - Среда выполнения
- **node-telegram-bot-api** - API для работы с Telegram
- **dotenv** - Управление переменными окружения
